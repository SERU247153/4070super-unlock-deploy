1. 연구 개요
--------------------------------------------------------------------------------
(1) 목적
  · 사진 몇 장만으로 새 자재를 식별하는 딥러닝 모델(YOLOv8 + DINOv2)을 만들어
    현장 Edge AI Node에서 판정한다.
  · 사람 작업 장면과 실제 입출고를 구분하여 적치장 자재의 입고/사용/반출을
    자동 기록한다.
  · 판정 결과만 LoRa(920MHz)로 전송하여 통신망이 없는 현장에서도 동작한다.

(2) 역할 분담
  · YOLOv8   : "어디에 몇 개" (자재·사람 검출)
  · DINOv2   : "무엇인지" (자재 종류 판별, 대표벡터 등록/갱신)
  · Edge Node: Raspberry Pi 5 또는 Jetson Nano — 판정만 수행
  · 데스크톱 : RTX 4070 SUPER — 학습·새 자재 등록 담당 (YOLOv8은 이쪽 시스템에만)
  · LoRa 보드: Nano ESP32 + RFM95W, 4층 PCB (자체 설계), UART 연결
  · 서버     : OpenStack Instance(RHEL 9), MQTT + PostgreSQL/MariaDB + Grafana,
               L2TP/IPsec VPN으로 현장 사무실과 연결

(3) 참고: YOLOv8 설치는 데스크톱(학습 시스템)에만 한다. Edge Node에는 경량
    변환본(ONNX/TensorRT/NCNN)만 배포한다.

--------------------------------------------------------------------------------
2. 시스템 구성
--------------------------------------------------------------------------------
[현장 적치장]
  카메라 → Edge AI Node(RPi5/Nano)
             ├ YOLOv8: 자재·사람 검출
             ├ DINOv2: 종류 판별 (대표벡터 코사인 유사도)
             ├ 사람 있으면 판정 보류, 3회 연속 동일 시 확정
             └ 결과 패킷 → UART → LoRa 보드 → 920MHz → 게이트웨이
[사무실]
  게이트웨이 → MQTT → (L2TP/IPsec VPN) → 서버(수집/DB/대시보드)
[집 네트워크]
  데스크톱(RTX 4070 SUPER) : YOLOv8 학습, DINOv2 미세조정, 새 자재 등록
  OpenStack Instance(RHEL 9) : 서버 역할
